# jp-reader

Static reading page for texts generated by the
[Anki Japanese Highlighter](https://github.com/Sajovara/anki-japanese-highlighter)
browser extension, published at https://sajovara.github.io/jp-reader/.

The extension opens it as `https://sajovara.github.io/jp-reader/#<text>`.
The text is base64url-encoded UTF-8 JSON in the URL fragment, which
browsers never send to the server - the page only decodes and renders
it locally. It's a normal web page so that other extensions (Yomitan,
...) work on it, which they can't on the extension's own pages.

Source of truth: `web-reader/` in the extension's repository.
